Monitor Acuity Calculator

When does more resolution matter?

How to use
  1. (Optional) Choose metric or imperial units under "Advanced Display Options"
  2. Under “Bird’s Eye View”, set the width of the horizontal line to your monitor/television size (measured diagonally)
  3. Set the height of the vertical line to how far you sit from the monitor/television
  4. Look under “Resolutions” to see which resolutions are actually noticable upgrades
